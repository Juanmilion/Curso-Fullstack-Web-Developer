# Ejercicio 1 – API Node.js conectada a MySQL

Este ejercicio tiene como objetivo comprobar la **conexión** de una **API desarrollada con Node.js y Express** a una base de datos **MySQL**, y la obtención de registros almacenados en una tabla.

## 📌 Objetivos

- Crear una base de datos denominada almacen en MySQL.
- Crear una tabla productos e insertar al menos dos registros.
- Inicializar un proyecto Node.js.
- Instalar y configurar las dependencias necesarias (express, mysql).
- Instalar y configurar nodemon como dependencia de desarrollo.
- Crear un archivo .gitignore para excluir node_modules.
- Conectar la API con la base de datos MySQL.
- Crear una ruta GET (/productos) que devuelva todos los registros de la tabla.
- Ejecutar el proyecto con nodemon y comprobar la petición mediante Postman.
