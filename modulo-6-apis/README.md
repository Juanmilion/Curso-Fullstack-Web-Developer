# Módulo 6 – Gestión de APIs con Node.js y Express

Este módulo tiene como objetivo practicar la creación y gestión de **APIs** usando **Node.js** y **Express**, incluyendo rutas, métodos HTTP, códigos de estado y operaciones CRUD.

## 📌 Objetivos del módulo
- Comprender la estructura de un proyecto Node.js con Express.
- Usar nodemon para ejecutar proyectos en modo desarrollo.
- Crear rutas propias para responder con JSON.
- Implementar los métodos GET, POST, PUT y DELETE.
- Validar datos recibidos en peticiones POST/PUT.
- Devolver códigos de estado HTTP adecuados.
- Ejecutar y comprobar las APIs con Postman.

---

## 📂 Ejercicios realizados

### 🧩 Ejercicio 1 – Enrutamiento de APIs
- Creación de un proyecto Node.js en el directorio `ejercicio1`.
- Instalación y configuración de nodemon y Express.
- Creación de rutas `/alumns` y `/teachers`.
- Devolución de datos de ejemplo en formato JSON.
- Ejecución del proyecto con nodemon y comprobación de las rutas con Postman.

### 📄 Ejercicio 2 – Uso de POST y códigos de estado
- Creación de un proyecto Node.js en el directorio `ejercicio2`.
- Instalación y configuración de nodemon y Express.
- Creación de la ruta `/players` con métodos GET y POST.
- Validación de los datos enviados en POST.
- Devolución de códigos de estado HTTP (`201` para éxito, `400` para error).
- Ejecución del proyecto y pruebas con Postman.

### 🌐 Ejercicio 3 – Operaciones CRUD
- Creación de un proyecto Node.js en el directorio `ejercicio3`.
- Instalación y configuración de nodemon y Express.
- Creación de la ruta `/books` con métodos GET, POST, PUT y DELETE.
- Validación de datos en POST/PUT y devolución de códigos de estado adecuados (`201`, `400`, `404`).
- Ejecución del proyecto y comprobación de todas las operaciones CRUD con Postman.
