# Ejercicio 1 – Node.js y Express: Enrutamiento de APIs

Este ejercicio tiene como objetivo comprobar el enrutamiento de **peticiones HTTP** en un proyecto **Node.js** usando **Express**.

---

## 📌 Objetivos

- Inicializar un proyecto Node.js.
- Instalar y configurar una dependencia de desarrollo (`nodemon`).
- Crear rutas propias en Express (`/alumns` y `/teachers`).
- Devolver datos en formato JSON desde cada ruta.
- Ejecutar el proyecto con nodemon y comprobar las peticiones con Postman.
