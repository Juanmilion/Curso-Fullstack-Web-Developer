# Módulo 4 – Testing

Este módulo tiene como objetivo introducir y practicar diferentes tipos de **testing en JavaScript**, utilizando herramientas como **Jest** para tests unitarios y **Cypress** para tests End-to-End, así como aplicar la metodología **TDD (Test-Driven Development)**.

## 📌 Objetivos del módulo
- Comprender la importancia del testing en el desarrollo de aplicaciones.
- Ejecutar tests unitarios con Jest.
- Realizar tests End-to-End (E2E) con Cypress.
- Aplicar el ciclo TDD: test → implementación mínima → refactorización.
- Verificar el correcto funcionamiento del código mediante pruebas automatizadas.

## 📂 Ejercicios realizados

### 🧪 Ejercicio 1 – Testing unitario con Jest
- Creación de un proyecto JavaScript con Jest.
- Implementación de una función que busca usuarios por DNI.
- Desarrollo de tests unitarios para comprobar la funcionalidad.
- Ejecución y validación de los tests.

### 🌐 Ejercicio 2 – Testing End-to-End con Cypress
- Desarrollo de una página HTML con interacción mediante JavaScript.
- Ejecución de la aplicación en un servidor local (Live Server).
- Instalación y configuración de Cypress.
- Creación de tests E2E que validan la interacción del usuario.
- Ejecución y comprobación de los tests.

### 🔁 Ejercicio 3 – Ciclos TDD con Jest
- Creación de un proyecto para aplicar TDD.
- Desarrollo de tests antes de implementar el código.
- Implementación de una función de formateo de fechas.
- Manejo de valores no válidos mediante tests.
- Refactorización del código asegurando que los tests siguen pasando.
