# Ejercicio 2 – Node.js + Express (envío de archivos)

Este ejercicio tiene como objetivo comprobar la creación de un proyecto **Node.js** con **Express**, y el envío de archivos como respuesta a peticiones HTTP.

---

## 📌 Objetivos

- Inicializar un proyecto Node.js.
- Instalar y configurar dependencias (`nodemon` y `express`).
- Crear un servidor Express básico.
- Responder a rutas con archivos (texto y PDF).
- Configurar scripts para ejecutar el proyecto con nodemon.
