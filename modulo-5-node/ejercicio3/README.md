# Ejercicio 3 – Servidor HTTP con Node.js y Express

Este ejercicio tiene como objetivo comprobar la implementación de una **lógica de respuestas a peticiones HTTP** utilizando **Node.js y Express**.

## 📌 Objetivos

- Inicializar un proyecto Node.js con `npm init`.
- Instalar y configurar **Express** para crear un servidor HTTP.
- Instalar **nodemon** como dependencia de desarrollo para ejecutar el proyecto en modo desarrollo.
- Configurar un script en `package.json` para ejecutar el proyecto con nodemon.
- Crear un archivo `.gitignore` para excluir `node_modules` del control de versiones.
- Implementar un servidor Express en `app.js`.
- Crear un método `GET` que reciba un parámetro y genere respuestas distintas según su valor.
- Ejecutar el proyecto y comprobar el funcionamiento de las rutas.
