# Ejercicio 1 – Node.js y uso de módulos

Este ejercicio tiene como objetivo comprobar la creación de un proyecto **Node.js**, la gestión de dependencias y el uso de **módulos** mediante la importación y exportación de funciones.

---

## 📌 Objetivos

- Inicializar un proyecto Node.js.
- Instalar y configurar una dependencia de desarrollo (`nodemon`).
- Crear y usar módulos propios en Node.js.
- Ejecutar un script con nodemon.
- Mostrar resultados por consola.
